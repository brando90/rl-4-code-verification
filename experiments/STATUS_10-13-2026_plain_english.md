## 2. The three ideas Brando remembers

Other names that appear below: **SWE-bench Verified / Lite** (benchmarks of real GitHub issue fixes, scored by the repository's own tests); **AlphaHebe / AlphaDiana / AlphaApollo** (Andrew Zhou's team's self-improving agent harness, which promotes an edit when a single score goes up); **AUROC** (area under the receiver operating characteristic curve: 0.5 is chance, 1.0 is perfect separation of passing from failing cells); **MBPP** and **VERINA** (external Python and Lean task sets used as training sources so that VBV1 stays held out); **`sorryAx`** (Lean's placeholder axiom for an unfinished proof; any proof using it earns zero); **R0 / R1 / R2 / L1v2** (experiment 13 version 2's steps: authored fixture acceptance, train-only diagnostic, full reproduction of the historical outputs, and the lock that freezes code and forecasts before any held-out factor is computed).

**(a) Supervised fine-tuning on Lean data: did it work?** Partly.

- `experiments/05_qwen3_base_models_vbv1_g8_pass_signal_sft_derisk/` showed the untrained Base models give essentially no signal: mixed-group share 0.000 [0.000, 0.004] (1.7B), 0.006 [0.002, 0.013] (4B), 0.000 [0.000, 0.004] (8B) over 896 tasks, so RL from Base would have nothing to learn from.
- `experiments/08_qwen3_base_matched_lean_sft_opus55_astra_teachers_vbv1_train_val_test/` then trained all four sizes identically (658 updates, 5,752,936 loss tokens each) on 1,315 teacher-written Lean files. **It did create signal:** on the test split the selected 8B checkpoint scores SCSC 0.1116 [0.0823, 0.1435] versus 0.0000 for Base 8B, and the selected 14B checkpoint 0.0869 [0.0651, 0.1095] versus 0.0023 for Base 14B (222 tasks x 8 samples each; one training run, so the intervals cover task sampling, not training seeds).
- **"Selection PARTIAL" means:** the protocol called a checkpoint RL-ready only if it passed three formatting and signal gates on the validation split (at least 972/1,080 responses extractable, at most 108/1,080 cut off at the token cap, at least 7/135 mixed tasks), and the goal was one token fraction at which all four sizes pass. No such common fraction exists: 8B first passes at the full budget (step 658), 14B at half (step 334), and **1.7B and 4B pass at no rung** (their final checkpoints still fail the formatting gates: 897 extracted / 184 capped and 946 / 134 of 1,080). So the two passing checkpoints are "unmatched diagnostics", not the matched cross-size warm start that was asked for. The 10-09-2026 decision note (`experiments/meetings/oct_9_2026/grpo_vs_codapo_vs_teacher_warm_start_decision.md`) adds that even 1.7B and 4B reach 20/135 and 32/135 mixed validation tasks after full SFT; what blocks them is formatting, not zero signal.
- A second Lean warm-start dataset exists but is unused: `experiments/02_rho_h_guided_lean_env_design_eval_vbv1_3_metrics/` phase A v3 kept 587 kernel-verified teacher files over 455/970 MBPP tasks (PARTIAL; owner Ethan).

**(b) Varun's predictive law and the IRT ability forecasts.**

- `experiments/14_irt_2pl_ability_vs_heldout_pass1_forecast_swebench_verified_164_systems/` is the positive result. On experiment 07's 164 x 424 SWE-bench Verified matrix with 2,000 half-splits at 50 tasks, a 2PL IRT model (two-parameter logistic: each task has a difficulty and a discrimination, each system an ability) forecasts held-out pass@1 with mean absolute error 0.0344 against 0.0554 for plain pass@1 on the same 50 tasks, difference +0.0210 [+0.0195, +0.0224], p-val=0.001 (system bootstrap); IRT is closer for 159/164 systems and beats a non-IRT regression control by +0.0022 [+0.0015, +0.0028]. The rank gain is real but small: Spearman +0.0040 [+0.0016, +0.0066], positive in 1,623/2,000 splits (share 0.811 [0.600, 0.839], p-val=0.052 against the 0.60 threshold), and it vanishes by 250 tasks. Verdict **CONTINUE**; next is Q2 (forecast when an SFT checkpoint starts giving RL signal, from experiments 05 and 08's per-task files, zero model calls).
- `experiments/13_irt_scsc_factor_guided_vs_direct_pass1_rl_sft_qwen3_vbv1_d013/` is the RL test of the same idea. **Version 1 failed by scorer design, not by science:** its scorer rejected 14,764 of 21,504 historical outputs before measuring them (6,739 measured, 14,765 unmeasured), so the equality gate could never pass; version 2's R1 diagnostic traced a 300-cell sample of those rejections to parse errors in 296/300 = 98.67% [96.62, 99.48]. **Version 2 has been running since 10-13-2026 11:41 PDT** (verified 11:44, commit `3ff9da2` at 11:43) with a scorer that measures every output; R0 and R1 passed (30/30 fixtures, 400/400 train cells) and the full reproduction R2 is at 11,163/38,784 cells as of 14:55 PDT. Its zero-call finding is worth remembering: on all 15 finished SFT checkpoints of experiment 08, VeriBench's kernel-checked factors equal the strict pass/fail outcome, so a factored *kernel* reward adds no learning signal; version 2 therefore builds per-declaration partial-credit factors first.
- The rho-H law itself (Varun's pre-RL equation) lives in `experiments/02_rho_h_guided_lean_env_design_eval_vbv1_3_metrics/` and is BLOCKED: no numeric forecast has been frozen and 0/4 training trajectories have run.

**(c) Factored or decomposed scores versus a single pass@1.**

- Done: `experiments/12_scsc_vs_hidden_gold_tests_vbv1_across_systems/` confirms the record's numbers exactly: system Spearman 0.891 [0.782, 0.900], AUROC 0.640 [0.583, 0.696], within-system Spearman 0.151 [0.074, 0.225]; SCSC runs 0.061 [0.052, 0.070] above the hidden-test pass rate on average. `experiments/07_scs4c_vs_pass1_swebench_across_models/` (phase A) shows the general-code version ranks systems like pass@1 (Spearman 0.985) and that partial credit carries capability signal (0.736), but is not a better small-sample ranker (H2 failed).
- Stopped: `experiments/09_qwen3_1p7b_grpo_scsc_scalar_vs_factor_feedback_vbv1_d013/` (the only RL run with a factored reward) never took an optimizer step because sampled tokens fell outside the trainer's recomputed sampling support; `experiments/10_hebe_promotion_gate_scalar_vs_factor_matrix_replay_swebench_verified_logs/` is locked but its 18-minute, zero-call phase A was never launched.
- Blocked: `experiments/02_rho_h_guided_lean_env_design_eval_vbv1_3_metrics/` (no trainer, no accepted references), `experiments/04_scsc_factor_guided_repair_and_rl_eval_vbv1_vbv2/` (adapter supports 0/24 external tasks), `experiments/11_hebe_gepa_factor_feedback_and_nonregression_gate_2x2_swebench_verified/` (no repository access).
- Net: the correlation half of the idea is established; the "factors help repair or training" half has zero measured cells anywhere in the repository.
