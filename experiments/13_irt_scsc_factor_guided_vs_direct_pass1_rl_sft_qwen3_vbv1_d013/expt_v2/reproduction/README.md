# Version 2 full reproduction and G0 harness

**Doc link:** <https://github.com/brando90/rl-4-code-verification/blob/main/experiments/13_irt_scsc_factor_guided_vs_direct_pass1_rl_sft_qwen3_vbv1_d013/expt_v2/reproduction/README.md>

**TLDR:** Measure the accepted R0-attempt-2 components once per unique source, reproduce each historical source-family oracle, and keep the 5,328 test cells inside their own process. No measurement is admitted before the published L1v2 binding.

The metadata-only builder checked source hashes and constructed 38,784 unique cells: 12,936 train, 20,520 validation and 5,328 test. The 3,240 base/ladder aliases reuse one compile/component receipt, with each family's original reader retained. Thus there are 42,024 oracle value/status comparisons over 38,784 unique sources. The 5,400 unavailable parent-ladder cells remain outside that available cohort and are separately declared. Index files permit reading one manifest record without repeatedly parsing the full manifest.

`run_all.py` launches two separate processes. The ordinary process handles train/validation; the opaque process handles test. The latter's public receipt contains completeness, hashes and equality only. Its source, raw process streams, component measurements, diagnostics and discrepancy details stay private. Inspecting a test discrepancy requires the numbered chronology amendment in PLAN section 3.

The two coordinators share memory slots and the fenced watchdog's persistent attempt ledger. Every child is bound to process identifier, start ticks and boot identifier; surviving child groups occupy their slots until they finish. A resumed coordinator first adopts/reconciles existing receipts. Only a missing receipt from an interrupted running attempt can consume the one identical infrastructure retry; measured, deterministic-limit, integrity-defect and unresolved terminal measurements cannot be rerun. Two attempts never reset across processes or boots. Every route has an exclusive coordinator lock.

Each worker runs under a 64 GiB address-space limit. Global concurrency is at most 48 and also bounded by half current available memory divided by R1's measured complete-cell 99th-percentile tree peak. New work pauses below 25% available host memory. Both processes run inside one aggregate systemd memory scope when supported. The execution lock records the actual admission and scope limit. Peak memory includes descendants, registered for watchdog adoption.

A source hash mismatch is an integrity defect. A declared timeout is a typed deterministic limit. Unknown frontend/process exceptions retain their full private evidence and produce an incomplete measurement; they never become missing observations silently or invented scores. The final gate requires the complete declared set, except typed deterministic limits, and every measured oracle value/status equal with no untyped consistency diagnostic. No partial receipt admits G0.

`g0.py` reads only the ordinary route after R2 PASS. Dense-only means nonzero variation in arm B's partial reward among the eight full-schedule samples while strict is constant. Its denominator is all 135 validation tasks. The predictive test uses mean 50%-rung B on tasks with zero 50%-rung strict successes to predict any full-schedule strict success. Thresholds remain 21/135 and area under the receiver-operating curve at least 0.65; a one-class outcome fails. Uncertainty uses 10,000 paired task-group draws, resampling the whole cohort before conditioning on zero earlier successes. The 1.7B and 8B strata are secondary. Missing required samples stay failures, without denominator reduction.

Only authored arrays and the existing authored vacuity example have exercised this harness before the lock. No validation/test factors have been computed. Deterministic tests cover source-access routing, the historical ladder readback and unknown status, opaque receipt sanitation, incomplete-gate refusal, and eight-sample/one-class G0 behavior.
