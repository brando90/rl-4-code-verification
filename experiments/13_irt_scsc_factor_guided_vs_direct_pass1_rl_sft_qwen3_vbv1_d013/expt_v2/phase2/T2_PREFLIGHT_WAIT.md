# Experiment 13 v2-S2: T2 pre-admission device wait

**Doc link:** <https://github.com/brando90/rl-4-code-verification/blob/main/experiments/13_irt_scsc_factor_guided_vs_direct_pass1_rl_sft_qwen3_vbv1_d013/expt_v2/phase2/T2_PREFLIGHT_WAIT.md>

**TLDR:** The last device guard detected another execution on the claimed device before constructing the runtime. No numbered T2 attempt was admitted and no response, optimizer update or admission statistic exists. The released reservation remains charged; a published additive reconciler returns this verified pre-runtime collision to device waiting.

The complete [T1 PASS](../RESULTS_T1_S2.md) was published at `0439f49` before the T2 controller started. T2's initial device observations found device 0 idle and unreserved. Another execution then appeared before `technical_supervisor.run` reached engine construction. The existing `check_lease` guard raised `RuntimeError: another execution now occupies the leased device`. The supervisor directory was never created, its runtime never launched, and the driver stopped before `technical_ledger.admit`.

[Saved collision evidence](T2_preflight_collision.json) records **0 responses, 0 optimizer updates, 0 admission statistics and 0 numbered T2 admissions**. The only lease is RELEASED, with verified cleanup and **0.015054962 device-hours** retained inside the unchanged 8.0-hour per-attempt and 10.0-hour cumulative T2 caps. No other owner's process was stopped or used. This is a device wait, as the master's instruction specifies; it is not a failed measured gate or a new scientific attempt. Amendment A4's non-probe preflight remains before numbered admission.

The [additive wait lock](../locks/T2_PREFLIGHT_WAIT_A6_S2.json) binds `preflight_wait.py`, its tests, the watchdog supervisor and the immutable failure evidence. It references the published LP successor at `d5961c9` and verifies all 4,681 existing physical bindings unchanged. **No existing frozen source, checkpoint, configuration, probe, sampler, seed, threshold, ledger path, cap or prior result changes.**

The reconciler accepts only this specific verified failure before runtime creation, with no admission and a released clean lease. It retains the initial state and dispatch evidence and writes each new wait poll separately. Each new reservation gets a unique stage identity under prospective T2 attempt 1, so every failed health reservation is charged to the same per-attempt and cumulative allowances. Busy devices return WAIT and consume no numbered attempt. After a fresh process-free claim, the unchanged engine preflight must pass before the original admission function creates T2 attempt 1. The original bound controller then resumes at its first generation stage.

A runtime-started failure, unknown cleanup, admitted gate, changed scientific binding or incomplete recovery receipt cannot take this path. An interrupted recovery requires reconciliation of its actual receipts, never replay. The poller is watchdog-registered, checks every 15 minutes when waiting, and starts the unchanged technical controller once after preflight recovery. This adds no permission to repeat a measured gate.

[Regression evidence](T2_preflight_wait_regression.json): **14 focused checks pass in 3.21 seconds**, including a reproduction using the actual runtime guard, rejection of other failure classes, preserved costs and exactly one successful admission. These checks use authored fixtures, no device and no model call. Required Lean integration: **1,133 passed, 3 skipped, zero failures in 601.42 seconds**, direct exit 0 ([receipt](T2_preflight_wait_publication_test.json)).
