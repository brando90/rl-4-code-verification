# Experiment 13 v2-S2 prospective online ability refits

**Doc link:** <https://github.com/brando90/rl-4-code-verification/blob/main/experiments/13_irt_scsc_factor_guided_vs_direct_pass1_rl_sft_qwen3_vbv1_d013/expt_v2/phase2/ONLINE_ABILITY_PREPARATION.md>

**TLDR:** The current-policy ability implementation is ready for prospective inclusion in the pilot lock. No actual-data fit or reinforcement-learning update has run; the complete Phase 1 and pilot admission requirements still apply.

`online_ability.py` keeps all item discrimination, difficulty and dispersion parameters fixed at the admitted train-anchor estimates. Before updates 11, 21, and so on, it accepts only earlier train rollouts from that same C-arm run. It refuses duplicate identities, held-out tasks, current/future updates, other arms and mixed run seeds. Missing measurements and zero component denominators carry no likelihood information; they are retained in the denominator-pattern receipt. Empty or constant observed component risk sets stop C; the prior alone cannot establish identification.

The fraction components use the frozen beta-binomial observation likelihood, preserving each output's numerator and denominator. The binary implementation component uses the identical expression with denominator one, which is exactly Bernoulli; a numerical regression verifies both loss and gradient equality. The ability prior is normal with standard deviation one, on the unchanged train-anchor scale. Every fit uses five fixed starts from seeds 1302011–1302015, L-BFGS-B with 2,000 iterations, maximum 50 line-search steps, function tolerance 1e-10, gradient tolerance 1e-7, and history size 20. All starts must converge with finite gradients and predicted-probability disagreement at most .02 on the fixed observed-item array.

Before accepting a component, central finite differences of step 1e-5 must agree with analytic gradients within 1e-5. A joint positive rescaling and translation of abilities/difficulties, with inverse discrimination scaling, must preserve the likelihood within 1e-9. One synthetic recovery draw uses the actual per-output denominator and missingness pattern at four fixed true abilities −1.5, −.5, .5 and 1.5, seed 1302241. The existing recovery criteria remain ability correlation at least .80 and mean absolute probability error at most .08. The normal-prior standard-deviation sensitivities .5 and 2 use the same five-start checks; their estimates and in-sample calibration means, bias and absolute error are reported. Calibration here is descriptive, not held-out forecasting or a new efficacy gate.

Every component result is persisted. A failed control or fit stops C without substituting previous or uniform weights. The initial current abilities must come from the full-schedule anchor calibration; the parent driver must bind that artifact, declare the complete earlier rollout inventory, and reserve a durable exclusive refit attempt before invoking this code. This preparation does not itself supply that execution lock or authorize a fit.

`score_training.py` separately preserves the actual training arm, seed, update and group identity while calling the unchanged extraction, declaration adapter and independent official oracle. Capped valid programs can still pass. Each scoring attempt is durable before its bounded worker starts; a completed receipt is recovered without rescoring. Missing generation remains missing and cannot later be silently replaced. It shares the frozen memory admission and cleanup primitives with anchor scoring, but does not relabel training outputs as anchor-policy outputs. The parent driver must verify its published scientific and input bindings before using the scoring primitive.
