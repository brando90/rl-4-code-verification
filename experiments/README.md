Causal repair and training outcomes remain unmeasured. [07_scs4c_vs_pass1_swebench_across_models](07_scs4c_vs_pass1_swebench_across_models/README.md), owned by Emily, defines SCS4C (the smooth conjunctive score for general code) and tests it against pass@1 across public SWE-bench Verified submissions; phase A is done (10-07-2026): on 164 systems SCS4C-T ranks like pass@1 (Spearman 0.985), partial credit on failed tasks tracks pass@1 (Spearman 0.736 [0.507, 0.801]), but 50-task SCS4C-T does not predict held-out pass@1 better than pass@1 itself (median Δ −0.012), so the H2 forecast failed.

Existing execution route (Brando, 09-30-2026): experiments run on the Stanford Network Analysis Project (SNAP) cluster, with Emily (@emxia18) assigned to the earlier runs. The shared launcher remains [`scripts/cc_prompt_run_experiment_on_snap.md`](../scripts/cc_prompt_run_experiment_on_snap.md); prior gates remain in [PLAN §6](../docs/PLAN.md#6-experiments-and-gates).
